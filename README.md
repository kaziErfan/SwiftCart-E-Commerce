1. null এবং undefined এর মধ্যে পার্থক্য হলো null কোন ভেরিয়েবলের এর ভ্যালু না দিলে ব্যবহার করা যায়। আর কোন ভেরিয়েবলের এর ভ্যালু না থাকলে JS undefined দেখায়। undefined সেট করাও যায় কিন্তু এটা বেস্ট প্র্যাকটিস না।

2. map ফাংশান দিয়ে কোন array এর element গুলো লুপ আকারে বের করা যায়। যেটা forEach দিয়েও করা যায়। পার্থক্য হচ্ছে map লুপ করে পাওয়া element গুলো দিয়ে আরেকটি নতুন array তৈরি করে যেটা forEach করেনা।

3. == এবং === এর মধ্যে পার্থক্য হলো === স্ট্রিক্টলি value কম্পেয়ার করে যেটা == করেনা। যেমন: value সেম হলেও যদি একটা স্ট্রিং আরেকটা নাম্বার হয় তাহলে === false দেখাবে কিন্তু == true দেখাবে। যেমন: 7 === "7" (false) আর 7 == "7" (true)

4. async/await এর বৈশিষ্ট্য হলো এটি প্রমিজ পূরন না হওয়া অর্থাৎ ডাটা ফেচ না হওয়া পর্যন্ত বাকি ফাংশানকে থামিয়ে রাখে।

5. Global scope মানে হলো কোডের যেকোন জায়গা থেকে কোন ভেরিয়েবল এক্সেস করা যায়। Function scope হলো শুধু মাত্র function এর মধ্যে কোন ভেরিয়েবল এক্সেস করা যাবে। আর block scope হলো {} - কার্লি ব্যাকেটের ভিতরে শুধুমাত্র ভেরিয়েবল গুলো এক্সেস করা যাবে।
